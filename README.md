# Mayflower State Bar Directory Workstation

Official 2000s-styled virtual workstation for the State Bar of Mayflower.

## Features
- **Public Bar Roster**: Registered attorney directory with 10-digit Bar License numbers and status badges.
- **Bar Examination Portal**: Official 10-question state bar exam with automatic grading and logging.
- **Bar Transfer Application Form**: Reciprocal bar transfer application form.
- **Central Database Portal**: Hidden database administration queue for reviewing, accepting, and denying applications.
